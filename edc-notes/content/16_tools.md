# Chapter T: Interactive calculators {.chap}

::: kid Play with the numbers
Change a value and watch what happens. Doubling $C$ in a filter, raising the temperature of a diode, adding an emitter resistor: seeing the answer move builds intuition faster than reading. Each calculator uses **exactly the formulas in these notes**, so you can also use them to check your own working on practice problems.
:::
