# Start here {.first}

::: kid How these notes work
Each chapter is built the same way, so you always know where you are:

1. **Words and symbols you need** (blue box, top of every chapter): every abbreviation and symbol used in that chapter, in plain English, *before* you meet it. Terms are also underlined with dots in the text: **hover or tap them** for the meaning.
2. **The kid version** (yellow box): the idea using an everyday picture, no maths.
3. **The real version**: exact definitions, diagrams and equations, with every step of each derivation shown.
4. **Worked examples** (green boxes): always in the same order: **Given → Find → Formula → Steps 1, 2, 3… → Answer → What it means**. No step is skipped, and every number is shown.
5. **Questions** (purple box) are **separate** from their **Answers and full solutions** (green box below). Try the questions first; then open the solutions, which are worked out step by step exactly like the examples.
:::

::: remember The colour code
🟨 yellow = simple picture &nbsp; 🟦 blue = words/symbols or formula &nbsp; 🟩 green = worked example or solution &nbsp; 🟪 purple = your practice questions &nbsp; 🟥 red = exam trap &nbsp; 🟧 orange = "check this": a slip or two versions in a slide or class solution &nbsp; <span class="tag">extra</span> = added from general textbook knowledge, not in your files.
:::

$$V_T=\frac{T}{11600}\approx 26\ \text{mV at }300\text{ K}\qquad \eta=1\ (\text{Ge}),\ 2\ (\text{Si})$$
$$\text{Turn-on voltage: }0.3\text{ V (Ge)},\ 0.7\text{ V (Si)}\qquad\text{Reverse leakage doubles every }10^\circ\text{C}$$
$$V_{BE}\approx0.7\text{ V},\qquad I_C=\beta I_B,\qquad I_E=(\beta+1)I_B,\qquad r_e=\frac{26\text{ mV}}{I_E}$$
