CHAPTER 15Circuit Simulation: SPICE, LTspice and MOSFET Models

Before spending millions on masks, every chip is simulated. This chapter covers what SPICE is, how it solves a circuit, the MOSFET model levels, the netlist and analyses, and the lab experiment from class.

Drive: 4_LTSpice (Class Notes, Notes_MOSFET_SPICE_Models, slides LT1 to LT5)
Explain like I'm 10

Building a real chip is like baking a giant cake that takes three months and costs a fortune, and you can't fix it once it's baked. So first you bake it in a video game. SPICE is that game: you describe the circuit as a list of parts and connections, and it calculates every voltage and current. If the game cake comes out flat, you change the recipe for free.

15.1 What SPICE is

  • SPICE = Simulation Program with Integrated Circuit Emphasis, from UC Berkeley, 1973 (open source). Versions: 1973 SPICE1 (FORTRAN), 1975 SPICE2, 1981 SPICE 2G.6, 1985 SPICE3 (rewritten in C).
  • Why simulate: fabrication is expensive and irreversible, so verify first. Commercial EDA vendors: Cadence, Synopsys, Mentor Graphics (Siemens), Tanner. Free tools: LTspice (Analog Devices, download from analog.com), PSpice Lite (Cadence OrCAD; limited to 64 nodes, 10 transistors, 2 op-amps, 65 digital primitives).
  • A general-purpose circuit simulator for non-linear DC, non-linear transient and linear AC analysis. It writes the circuit equations with KCL and KVL using modified nodal analysis and solves non-linear devices iteratively with Newton's method (linearise, solve, repeat until the answer stops changing: "convergence").
  • A device model is an analytical expression built from theory and measurement. Two kinds: device (primitive) models (.model) and subcircuit models (.subckt, a block built from other parts). A model reproduces only the behaviour its equations contain, not every quirk on a datasheet.

Analyses

  • .op / .dc: static operating point and DC sweeps (datasheet DC curves)
  • .ac: small-signal frequency response (gain, phase, capacitance effects)
  • .tran: time response, like an oscilloscope
  • Monte Carlo: random component variation, run many times to see the spread

LTspice survival kit (LT3)

  • F5 or Ctrl-X: delete; F7: move; F8: drag (keeps wires attached)
  • Ctrl-R: rotate; Ctrl-E: mirror
  • Right-click a part to enter its value or model
  • .include a model file; put dot-commands on the schematic as "SPICE directives"

15.3 The SPICE diode model (LT4)

  • Equivalent circuit: the ideal exponential diode current IF, a junction capacitance Cj and a series resistance RS.
  • Cj = Cj0/(1 − V/Vbi)M (M = grading coefficient; ½ for an abrupt junction, matching Chapter 13).
  • N = emission coefficient = the ideality factor η of Chapter 13: I = IS(eV/NVT − 1).
  • Class example: .model 1mA_diode D (Is=100pA n=1.679) with .DC VD 0V 800mV 10mV: the simulator used as a curve tracer.
  • A DC restorer (clamper) example: a PULSE(−3 7 …) source, 1 μF and a 1N4148, analysed with .TRAN 100u 10m.

15.4 The MOSFET model in SPICE

{{fig:spice_eqckt|The Level-1 MOSFET equivalent circuit from your class notes: the current source ID between internal nodes D′ and S′, series resistances, gate capacitances, and the two reverse-biased body diodes with their depletion capacitances.}}
  • ID = f(constants μn, μp, Cox, Vth; variables VGS, VDS), placed between the internal drain D′ and source S′.
  • RD, RS: series resistances of the drain and source regions.
  • Cgd, Cgs, Cgb: gate (MOS) capacitances. In Level 1 they follow the Meyer model, different in triode and saturation and smoothed at the boundary.
  • D–B and S–B diodes (always reverse-biased in normal use) with their depletion capacitances Cdb, Csb.
  • Level 1 in SPICE form: ID = (K′/2)(W/Leff)[2(VGS − VT)VDS − VDS²](1 + λVDS), with K′ = μCox and Leff = L − 2LD. This is exactly your triode formula ① with CLM (Chapter 11). Effective sizes use parameters such as LD, WD, XL, XW, LMLT, WMLT.

Model generations (LT5): 1st (Levels 1, 2, 3); 2nd (BSIM, BSIM2, HSPICE Level 28); 3rd (BSIM3 / Level 7/49, adding stress, sub-threshold, noise, gate tunnelling and temperature effects). The second-order effects that need BSIM3 below 0.8 μm (class notes): short-channel threshold shift, sub-threshold conduction, velocity saturation, charge-controlled capacitances.

  • Model file = a text file of technology parameters (.model or .lib), loaded with .include. PTM (Predictive Technology Models) provide files for 180 nm down to 90/65/45/32/22/16 nm. All devices in one circuit must use the same technology.
  • Rule of thumb from the Drive: hand calculations use Level 1; EDA sign-off uses BSIM.

15.5 Experiment 6: nMOS characteristics and the inverter in LTspice

The lab exactly as in your class notes
  1. Place an nmos4 symbol (4 terminals). Set L = 0.18 μm (180 nm), W = 10 μm; .include the 180 nm model file.
  2. Source V2 on the drain (VDS), V1 on the gate (VGS); source and body grounded.
  3. Nested DC sweep: VDS from 0 to 1.8 V in 0.01 V steps, for VGS = 0 to 1.8 V in 0.3 V steps:
    .dc V2 0 1.8 0.01 V1 0 1.8 0.3
  4. Plot ID (Id(M1)): a family of output curves like Chapter 11's figure.
  5. Transfer curve: sweep VGS at fixed VDS and find gm = ∂ID/∂VGS (LTspice can plot d(Id(M1))).
  6. Build the CMOS inverter (add a pmos4 with its source and body at VDD = 1.8 V), sweep Vin with .dc to get the VTC (Chapter 12), then apply a PULSE input with .tran to see the transient (propagation delay).
Practice: write the SPICE lines for (a) an nMOS M1 with drain node d, gate g, source and body at 0, model NMOS180, W = 10 μm, L = 0.18 μm; (b) a sweep of VDS 0 to 1.8 V for VGS = 0.6, 1.2, 1.8 V; (c) a 10 ns transient.

(a) M1 d g 0 0 NMOS180 W=10u L=0.18u (pin order D G S B).

(b) VDS d 0 0, VGS g 0 0, .dc VDS 0 1.8 0.01 VGS 0.6 1.8 0.6.

(c) .tran 10n (or .tran 0.01n 10n to set the step), with a source such as VIN in 0 PULSE(0 1.8 1n 50p 50p 2n 4n).

Exam traps
  • MOSFET pin order is D G S B; BJT is C B E.
  • SPICE solves non-linear circuits with Newton's method; non-convergence means the iteration did not settle.
  • Level 1 = Shichman–Hodges square law: no sub-threshold current, no short-channel effects.
  • "N" in a diode model is the emission coefficient (ideality factor), not a doping.
