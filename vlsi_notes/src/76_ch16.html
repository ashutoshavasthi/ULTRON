Explain like I'm 10

A memory chip is a giant apartment block where each flat holds one bit (a 0 or a 1). To visit a flat you need its floor number (the row, picked by the word line) and its door number (the column, reached through the bit line). A ROM is a block where the furniture was cemented in when it was built: you can look, not change. A RAM lets you move furniture any time, but if the power goes off (the lights go out) everyone forgets where everything was.

16.1 What a memory is and how it is judged

  • Memory = an electronic circuit that can store data. Bit = the smallest unit of data that can be stored. The basic building block is a 1-bit cell, replicated in an array. Modern memories are built from MOSFETs for density, low power and speed.

Testing (typed notes: design for testability)

After fabrication every chip must be tested against expected outputs. With thousands of inputs, testing every combination is impossible (input-vector explosion: n inputs give 2n combinations), so tests use random samples / chosen test patterns and fault models (what physical defects can occur and what wrong outputs they would cause). Designing the chip so it is easy to test is design for testability (DFT).

16.2 Classification

The board classifies memories by (i) type of data storage and (ii) type of data access:

Read-only memory (ROM)

  1. Only retrieval of data (mostly reads)
  2. Data stored at the time of fabrication or programming
  3. Non-volatile: keeps data with the power off

Mask-programmed ROM (fixed by a mask during manufacture) · PROM (programmable once by the user in the field) · EPROM (erasable, with UV light, and re-writable many times) · EEPROM (electrically erasable) · Flash (high-density electrically erasable; SD cards, SSDs). Programmable kinds have limited write endurance and writes are much slower than reads.

Read/write memory (RAM)

  1. Allows re-writing of data
  2. Volatile: loses data when power is removed
  3. Random access: no need to go through locations in sequence; fast reads and writes

SRAM (static RAM: cross-coupled transistors hold the bit as long as power is on) · DRAM (dynamic RAM: the bit is charge on a capacitor that leaks and must be periodically refreshed).

16.3 Memory organisation

{{fig:mem_array|A random-access memory: the row decoder fires one word line; the column decoder picks the bit line; the cell at the crossing is read or written.}}
  • Memory cell: each stores one bit. Cells are placed in an array (the memory core) surrounded by peripherals (decoders, sense amplifiers, drivers, timing).
  • Row decoder: N address bits A1…AN select one of 2N word lines (an N-input decoder has 2N outputs).
  • Word lines = horizontal lines connecting all the cells in a row. Bit lines = vertical lines used to read or write a specific cell.
  • Column decoder: M address bits pick one of 2M bit lines.
  • Storage capacity = 2N × 2M bits (the board writes 2m × 2n).
  • To read or write a cell, both its word line and its bit line must be activated.
Worked: a 1 Mbit memory is organised as a square array. How many rows and columns, and how many address bits go to each decoder? What is the total address width?

1 Mbit = 220 bits. Square: 210 × 210 = 1024 rows × 1024 columns. Row decoder N = 10 bits, column decoder M = 10 bits, total 20 address bits. Why square? It keeps the word and bit lines (and so their capacitance and delay) as short as possible.

16.4 ROM circuits: the 4 × 4 NOR ROM (your board)

{{fig:nor_rom|The 4-bit × 4-bit NOR-based ROM drawn on the board. Transistor positions copied from the board: R1 → C1, C3; R2 → C1, C2; R3 → C2, C3; R4 → C1, C4.}}
  1. Each column (bit line C1 to C4) has a pMOS pull-up with its gate grounded (always ON): the pseudo-nMOS load of Chapter 12. With no row selected, every column sits at 1.
  2. Rows R1 to R4 (word lines, driven by the row decoder) go to the gates of the nMOS cells. Exactly one row is 1 at a time.
  3. At a crossing (Ri, Cj): an nMOS present ⇒ when Ri = 1 it turns on and pulls Cj to 0. No transistor ⇒ Cj stays 1.
  4. Each column is a NOR of the rows that have transistors on it (any of them high ⇒ 0), hence "NOR ROM".
  5. The data is programmed by placing or omitting transistors at fabrication (a mask-programmed ROM).

Practice: design a 4 × 4 NOR ROM storing R1 = 1010, R2 = 0111, R3 = 1111, R4 = 0000. Where do the transistors go? How many are needed?

Put a transistor wherever the stored bit is 0. R1 = 1010 ⇒ C2, C4. R2 = 0111 ⇒ C1. R3 = 1111 ⇒ none. R4 = 0000 ⇒ C1, C2, C3, C4. Total 7 nMOS + 4 pull-ups.

Beyond your notes: NAND ROM, and the programmable ROMs

In a NAND ROM the cell transistors of a column are in series; unselected rows are held high (all on) and the selected row goes low. It is denser (no ground contact per cell) but slower. EPROM/EEPROM/Flash cells are MOSFETs with an extra floating gate buried in the oxide: trapping electrons on it raises Vth, so the cell no longer turns on when its word line rises, storing a different bit. EPROMs are erased by UV light; EEPROM and Flash are erased electrically by tunnelling (Flash erases a whole block at once, which makes it dense and cheap).

16.5 RAM cells: SRAM and DRAM

{{fig:sram_dram|Left: the six-transistor SRAM cell. Right: the one-transistor one-capacitor DRAM cell.}}
Beyond your notes: how the cells work (the typed notes name them; standard detail added)

SRAM (6T)

  • Two CMOS inverters connected in a loop (cross-coupled): Q feeds the second inverter, which feeds back Q̄ into the first. The loop has two stable states, so it holds a bit as long as power is on with no refresh.
  • Two nMOS access transistors connect Q and Q̄ to the bit lines BL and BL̄ when the word line WL = 1.
  • Read: precharge BL and BL̄ high, raise WL; the side storing 0 pulls its bit line down a little; a sense amplifier detects the difference.
  • Write: drive BL/BL̄ to the new value strongly and raise WL; the drivers overpower the inverters.
  • Fast, no refresh, but 6 transistors per bit ⇒ large and expensive. Used for caches and registers.

DRAM (1T1C)

  • One access transistor and one storage capacitor CS: charged = 1, empty = 0.
  • Write: raise WL and drive BL to VDD or 0.
  • Read: precharge BL to VDD/2, raise WL; CS shares its charge with the much bigger bit-line capacitance CBL, moving BL slightly up or down: ΔV = (VS − VDD/2)·CS/(CS + CBL). Reading destroys the stored charge, so the sense amplifier writes it back.
  • Charge leaks through the transistor and junction (Chapter 13 generation current), so every cell is refreshed every few milliseconds.
  • Only 1 transistor per bit ⇒ the densest, cheapest RAM. Used for main memory.
Worked: a DRAM cell has CS = 25 fF, the bit line CBL = 250 fF, VDD = 1.2 V, precharge 0.6 V. What bit-line swing does the sense amplifier see when reading a 1 (cell at 1.2 V) and a 0?

ΔV = (VS − 0.6) × 25/(25 + 250) = (VS − 0.6) × 0.0909. Reading a 1: (0.6) × 0.0909 = +55 mV. Reading a 0: (−0.6) × 0.0909 = −55 mV. These tiny signals are why DRAM needs sensitive sense amplifiers, and why CS can't be shrunk freely.

Exam traps
  • Word lines are rows (horizontal), bit lines are columns (vertical).
  • N address bits select 2N lines; capacity = 2N × 2M bits.
  • In a NOR ROM a transistor at a crossing stores a 0; no transistor stores a 1.
  • ROM is non-volatile; RAM is volatile. "Random access" means any location in the same time, not "random data".
  • SRAM: no refresh, 6T, fast, big. DRAM: refresh, 1T1C, dense, destructive read.
