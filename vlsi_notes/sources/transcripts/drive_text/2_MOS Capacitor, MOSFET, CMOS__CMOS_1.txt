CMOS Inverter Basics – I
1. Introduction to the CMOS Inverter
The CMOS inverter is considered the “main workout” of all digital VLSI circuit design. Its primary function
is to perform logic inversion, meaning it quickly changes a logical 1 to a 0, and a logical 0 to a 1.
Logic Levels:
1 corresponds to VDD (the applied positive voltage).
0 corresponds to VGND (Ground).
Inverting Action: If the input is 1, the output is 0. If the input is 0, the output is 1.
2. Structure and Functionality
A basic CMOS inverter consists of two types of transistors:
1. M2: PMOS (P-type MOSFET): Known as the Pull Up Device (PU), responsible for pulling the output
voltage from 0 to 1.
2. M1: NMOS (N-type MOSFET): Known as the Pull Down Device (PD), responsible for pulling the
output voltage from 1 to 0.

4. Static Behavior Characteristics
Static behavior refers to the device operation when the input is held steady at 0 or 1 for a long time (not
switching).
A. Power Consumption
Static Power Consumption is Very Small: In the static condition, there is no direct path between
VDD and ground (since one transistor is always OFF). This prevents a short-circuit current, resulting in
very low power dissipation levels.

High Input Impedance: Input signals are applied to the gate side, which is separated from the channel
by a dielectric (oxide layer). Because the oxide is an insulator, virtually no current flows into the input,
making the input impedance (change in voltage / change in current) very high.
Fan Out: This refers to the capability of a single device to drive a large number of other identical
devices.
Static Fan Out: Due to the high input impedance, ideally, a single inverter could drive an infinite
number of devices in static mode.
Dynamic Fan Out: In dynamic (transient/switching) mode, high fan out degrades the speed
(transient response). This is because driving many devices means the total capacitance (C_L) is
larger, requiring more time to charge or discharge, thereby slowing down the frequency.
Low Output Impedance: The output node is always connected to a node with very low impedance
(either VDD or Ground). This low output impedance makes the device less prone to noise and results
in a high Signal-to-Noise Ratio (SNR).
C. Ratioless Logic Level (Full Swing)
The static behavior (getting a full 0 or a full 1 output) is independent of the Aspect Ratio (

the PMOS and NMOS devices.
Full Swing: The inverter is able to achieve a full swing of the signal, meaning the output voltage
charges fully up to VDD (1) and discharges fully down to 0, without losing any signal strength.

Gain
A. Voltage Transfer Characteristics (VTC) and Switching Threshold
The Voltage Transfer Characteristics (VTC) plots how the output voltage (V_out) varies as the input voltage
(V_in) is changed from 0 to VDD.
Switching Threshold: This is a crucial characteristic, defined as the input voltage at which the
transition between 0 to 1 and 1 to 0 takes place. It is calculated directly from the VTC.
Deriving the VTC: The VTC curve is found by plotting the current-voltage (IV) characteristics of the
PMOS and NMOS devices and locating the points where the currents flowing through both are
