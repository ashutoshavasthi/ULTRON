3. Linear versus non-linear networks

A network is linear if it obeys the principle of superposition, which has two parts:

Additivity: f(x₁ + x₂) = f(x₁) + f(x₂)    Homogeneity: f(a·x) = a·f(x)
  • Linear: R, L, C (constant), linear dependent sources, ideal transformers.
  • Non-linear: diode, transistor large-signal, iron-core inductor (saturation), varistor, resistor with v = i² law, any element where R depends on v or i.
  • A circuit with only linear elements and independent sources is still linear with respect to the sources (zero-state response). With non-zero initial conditions it is "incrementally linear".
GATE trap: Power is NOT linear (p = i²R). Superposition applies to voltages and currents only, never to power. A line y = mx + c is not linear in the system sense (c ≠ 0 violates homogeneity), though it is "incrementally linear".

4. Time-variant and time-invariant networks

  • Time-invariant (LTI): element values do not change with time. A delay in the input produces the same delay in the output: x(t − t₀) → y(t − t₀).
  • Time-variant: some parameter depends on t, e.g. R(t) = R₀(1 + sin ωt), a switch operating periodically, a varactor driven by a pump, a rotating-machine inductance L(θ(t)).
Test: Apply x(t), get y(t). Apply x(t − t₀). If output is y(t − t₀) for every t₀, the system is time-invariant. Note that switching a switch once at t = 0 is usually treated as an initial-condition problem, and the network is still LTI for t ≥ 0.

5. Passive versus active networks

Passive: the total energy delivered to the network from t = −∞ to t is never negative:

W(t) = ∫−∞t v(τ)·i(τ) dτ ≥ 0   for all t and all possible v, i
  • Passive: R, L, C, mutual inductance (k ≤ 1), ideal transformer, gyrator.
  • Active: independent sources, dependent sources, op-amps, transistors, negative resistance, tunnel diode in its negative-slope region.
  • A passive network cannot give a power gain. It can store energy and return it later, but never more than it absorbed.
  • Passive network driving-point functions are positive real; poles on the jω axis must be simple with positive real residues.

6. Linear, lumped, finite, passive, bilateral (LLFPB) networks

LetterMeaningWhy it matters
LLinearSuperposition, Thevenin and Norton hold
LLumpedFinite-order ODE; KCL/KVL apply
FFiniteFinite number of elements (no infinite ladders; infinite ladders may need distributed treatment)
PPassiveNo internal energy sources; ∫vi dt ≥ 0
BBilateralSame v–i relation for either direction of current; this gives reciprocity (and symmetric Z, Y matrices)
  • Bilateral: R, L, C. Unilateral: diode, transistor, any element whose behaviour depends on direction.
  • Networks with dependent sources are generally non-reciprocal, so Z₁₂ ≠ Z₂₁ and the reciprocity theorem fails.
  • Thevenin/Norton/superposition require linearity only. Bilateral is not required (they work with dependent sources). Reciprocity needs LLFPB.

7. Stable and unstable networks

A network is BIBO stable if every bounded input gives a bounded output. For a lumped LTI network, check the poles (roots of the characteristic equation):

Pole locationNatural responseVerdict
All in the open left half plane (σ < 0)Decays to zeroStable
Simple poles on the jω axis (e.g. ±jω₀)Sustained oscillation (lossless LC)Marginally stable (not BIBO stable: resonant input makes the output unbounded)
Repeated poles on jω axisGrows like t·sin ω₀tUnstable
Any pole in the right half planeGrows like eσtUnstable
Any RLC network with positive R, L, C and only independent sources is stable (poles in the left half plane, or simple on the jω axis if lossless). Instability needs an active element: negative resistance or a dependent source with enough gain / positive feedback.
Example. A source v with series 2 Ω feeding a node that has 4 Ω and a CCCS drawing 5·(v/4) from the node: the port sees Req = −2 Ω. With a capacitor across it, the characteristic equation becomes RC s − 1 = 0 → s = +1/(RC) → growing exponential → unstable (see Problem 4).

8. Network theorems

8.1 Superposition theorem

In a linear network with several independent sources, the response (voltage or current) = algebraic sum of responses due to each independent source acting alone.

  1. Keep one independent source; turn others off: voltage source → short, current source → open.
  2. Keep every dependent source in the circuit (and re-express the control variable for that sub-circuit).
  3. Add the partial responses with signs.
Traps: (i) Never kill a dependent source. (ii) Not valid for power. (iii) Control variable changes in each sub-circuit: vx = vx′ + vx″, not the same number.

8.2 Thevenin's theorem

Any linear two-terminal network ≡ a voltage source Vth (= open-circuit voltage Voc) in series with Rth.

Circuit has…Method for Rth
Only independent sources and resistorsTurn off independent sources, find Req at the terminals
Independent and dependent sourcesRth = Voc / Isc (find both), or turn off independent sources only, apply a test source Vt (or It) and compute Vt/It
Only dependent sourcesVoc = 0 (no independent excitation, assuming zero initial energy), so find Rth with a test source. The result may be negative.
Trap: Do not turn off a dependent source when computing Rth, and do not use Rth = Voc/Isc if Voc = Isc = 0 (use the test-source method instead).

8.3 Norton's theorem

Any linear two-terminal network ≡ a current source IN (= Isc) in parallel with RN = Rth. Source transformation: Vth = IN·Rth.

Source transformation with dependent sources is allowed, but do not transform away the branch that contains the controlling variable (or keep the control variable explicitly tracked).

8.4 Maximum power transfer theorem

AC, only RL adjustable (XL fixed)RL = √(Rth² + (Xth + XL)²)—
  • Efficiency at max power = 50 % (for the Thevenin equivalent; the real internal circuit may dissipate differently, since Rth is not the actual dissipation when dependent sources are present).
  • Maximum efficiency (→ 100 %) needs RL ≫ Rth, which is a different condition from max power.
  • If Rth < 0, the theorem does not apply in the usual form (see Problem 4).
  • If the source resistance is fixed and the load is fixed but the source side can vary, max load power is when Rsource = 0, not a match.

9. Star–Delta (Y–Δ) transformation

Δ → Y: RA = RABRAC / (RAB + RBC + RCA)   (resistors adjacent to node A, over the sum)
Y → Δ: RAB = (RARB + RBRC + RCRA) / RC   (sum of pairwise products over the resistor opposite)
Balanced case: RΔ = 3RY. Same for impedances (ZΔ = 3ZY), valid for complex Z. Use it to solve unbalanced bridges, and note that the transformation is valid only if the network's internal nodes are not connected to anything else (the star centre is internal).

Problem 1 Thevenin, Norton and max power (independent V + I, CCCS)

In the circuit, a 10 V source with 2 Ω in series feeds node 1. Node 1 has a 4 Ω resistor to ground (current Ix flows down through it) and a 2 Ω resistor to terminal a. At terminal a there is also an independent 1 A current source pushing current into a, and a dependent current source 2Ix also pushing current into a (both from ground). Terminal b is ground.

 10V ─(+) ── 2Ω ──●node1────── 2Ω ──●a ←─ 1A (from ground)
                  │                 ←─ 2·Ix (from ground)
                 4Ω ↓Ix             
                  │                 
                 GND ───────────────●b (ground)

(a) Find Vth and Rth seen from a–b. (b) Find the Norton current. (c) Find the maximum power deliverable to a load RL connected across a–b, and the value of RL.

Solution

Open circuit (no current leaves a): Ix = v₁/4. At node a: current leaving through the 2 Ω = injected current.

(va − v₁)/2 = 1 + 2(v₁/4) ⟹ va = 2v₁ + 2

Node 1: (v₁ − 10)/2 + v₁/4 + (v₁ − va)/2 = 0 → 1.25v₁ − 5 − (v₁ + 1) = 0 → 0.25v₁ = 6 → v₁ = 24 V, va = 50 V.

Short circuit (va = 0): node 1: v₁/2 − 5 + v₁/4 + v₁/2 = 0 → v₁ = 4 V, so Ix = 1 A. Isc = v₁/2 + 1 + 2Ix = 2 + 1 + 2 = 5 A.

(a) Vth = 50 V, Rth = 50/5 = 10 Ω. (b) IN = 5 A (parallel with 10 Ω). (c) RL = Rth = 10 Ω, Pmax = Vth²/(4Rth) = 2500/40 = 62.5 W.

Check by test source: short the 10 V, open the 1 A, keep 2Ix. Apply a test source V at a. Node 1: v₁/2 + v₁/4 + (v₁ − V)/2 = 0 → v₁ = 0.4V, so Ix = 0.1V. The test source supplies I into a: I + 2Ix = (V − v₁)/2 = 0.3V → I = 0.1V → Rth = V/I = 10 Ω ✓.

Problem 2 Superposition with a VCVS (independent V + I, dependent V)

A node x is connected to: an 18 V source through a 5 Ω resistor; ground through 10 Ω; ground through a series branch of 4 Ω and a VCVS with value 0.4Vx (its + terminal toward the 4 Ω resistor, − terminal at ground); and an independent current source of 2.7 A injecting into x.

(a) Find Vx using superposition. (b) Find the power delivered by the 18 V source.

Solution

Branch current into the 4 Ω + VCVS branch = (Vx − 0.4Vx)/4 = 0.15Vx. Nodal equation at x: (Vx − 18)/5 + Vx/10 + 0.15Vx = 2.7, i.e. total conductance 0.2 + 0.1 + 0.15 = 0.45 S.

18 V alone (current source open, VCVS kept): 0.45Vx′ = 18/5 = 3.6 → Vx′ = 8 V.

2.7 A alone (18 V shorted, VCVS kept): 0.45Vx″ = 2.7 → Vx″ = 6 V.

(a) Vx = 8 + 6 = 14 V.

(b) Current out of the 18 V source = (18 − 14)/5 = 0.8 A → P = 18 × 0.8 = 14.4 W (delivered).

Check: KCL at x: 0.8 + 2.7 = 3.5 A in; out = 14/10 + 0.15×14 = 1.4 + 2.1 = 3.5 A ✓.

Problem 3 Star–Delta on an unbalanced bridge, then a source

A bridge has nodes A, B, C, D with resistors RAB = 6 Ω, RAC = 3 Ω, RBC = 3 Ω (the bridge arm), RBD = 3 Ω, RCD = 6 Ω. A 21 V source is connected across A and D. Find the total current from the source.

Solution

Convert Δ(A,B,C) to Y with centre O: sum = 6 + 3 + 3 = 12 Ω.

RA = (6×3)/12 = 1.5 Ω,   RB = (6×3)/12 = 1.5 Ω,   RC = (3×3)/12 = 0.75 Ω

From O to D: path via B: 1.5 + 3 = 4.5 Ω; via C: 0.75 + 6 = 6.75 Ω. In parallel: (4.5×6.75)/(11.25) = 2.7 Ω.

RAD = 1.5 + 2.7 = 4.2 Ω, so I = 21/4.2 = 5 A.

Problem 4 Negative Thevenin resistance (independent V, CCCS) and stability

A 10 V source in series with 2 Ω feeds node a. Node a has a 4 Ω resistor to ground (current Ix = va/4 flowing down) and a CCCS that injects 5Ix into node a from ground. Terminals: a and ground.

(a) Find Voc, Isc, Rth. (b) Can the maximum power transfer theorem be applied? (c) If a capacitor C is connected across a–ground, comment on stability.

Solution

Open circuit: (va − 10)/2 + va/4 − 5va/4 = 0 → 0.5va − 5 − va = 0 → Voc = −10 V.

Short circuit (va = 0 so Ix = 0): Isc = 10/2 = 5 A.

Rth = Voc/Isc = −2 Ω. Check with a test source (10 V shorted): I = V/2 + V/4 − 5V/4 = −V/2 ⟹ V/I = −2 Ω ✓.

(b) No. The standard theorem (RL = Rth) needs Rth > 0. Here the equivalent source is active and RL = 2 Ω gives V = VthRL/(RL + Rth) → division by zero: power grows without bound in the model, which signals instability, not a maximum.

(c) With the capacitor: C dv/dt = −(v − vth)/Rth → the pole is at s = −1/(RthC) = +1/(2C) > 0 → unstable (growing exponential until the circuit saturates).

Problem 5 Capstone – all six source types in one Thevenin problem

Circuit (ground is the common node):

  • Independent voltage source 12 V from node 1 to ground.
  • R₁ = 2 Ω between nodes 1 and 2. R₂ = 4 Ω from node 2 to ground; Ix is the current through R₂ (node 2 → ground), so Ix = v₂/4.
  • Independent current source 2 A injected into node 2.
  • R₃ = 2 Ω between nodes 2 and 3. R₄ = 4 Ω from node 3 to ground.
  • CCCS 3Ix injected into node 3 (from ground).
  • VCCS gmv₂ with gm = 0.25 S, drawing current out of node 3 into ground.
  • From node 3, in series: VCVS of value 0.5v₂ (vp = v₃ + 0.5v₂), then CCVS of value 2Ix (volts, with r = 2 Ω; vq = vp + 2Ix), then R₅ = 3 Ω to the output terminal a.
12V─●1─2Ω─●2─2Ω─●3──(+0.5v2)──(+2Ix)──3Ω──● a
        │   │ ↓Ix  │  │    ↑3Ix (CCCS in)
        │   4Ω  ↑2A  4Ω   ↓0.25·v2 (VCCS out)
       GND  GND     GND  GND                ● b = ground

(a) Find Vth and Rth across a–ground. (b) Find the maximum power to a load. (c) What is the voltage across a load of 7 Ω?

Solution

Open circuit (no current in R₅, so the VCVS/CCVS branch carries no current):

Node 2: (v₂ − 12)/2 + v₂/4 + (v₂ − v₃)/2 = 2 → 1.25v₂ − 0.5v₃ = 8 … (i)

Node 3: (v₃ − v₂)/2 + v₃/4 + 0.25v₂ = 3(v₂/4) → 0.75v₃ = v₂ → v₃ = (4/3)v₂ … (ii)

(ii) in (i): 1.25v₂ − (2/3)v₂ = 8 → v₂ = 96/7 V, v₃ = 128/7 V.

va = v₃ + 0.5v₂ + 2Ix = v₃ + 0.5v₂ + 0.5v₂ = v₃ + v₂ = 224/7 = 32 V. So Vth = 32 V.

Short circuit (va = 0): the branch now carries Isc, which leaves node 3 (adds Isc to node 3 outflow). Since vq = v₃ + v₂ and Isc = vq/3 = (v₃ + v₂)/3.

Node 3: 0.75v₃ − 0.5v₂ + 0.25v₂ + Isc = 0.75v₂ → 0.75v₃ + (v₃ + v₂)/3 = v₂ → (13/12)v₃ = (2/3)v₂ → v₃ = (8/13)v₂.

Node 2 (i): 1.25v₂ − (4/13)v₂ = 8 → v₂ = 416/49 V, v₃ = 256/49 V. Isc = (256 + 416)/(49×3) = 672/147 = 32/7 A.

Rth = 32 / (32/7) = 7 Ω.

(b) RL = 7 Ω, Pmax = 32²/(4×7) = 1024/28 = 256/7 ≈ 36.6 W.

(c) With RL = 7 Ω (matched): VL = 32 × 7/14 = 16 V.

Lesson: Rth = Voc/Isc works even when all four kinds of dependent sources are buried inside. The hard part is writing nodal equations carefully, with the VCCS direction (out of node 3) and the CCCS direction (into node 3) handled with the correct signs.

11. Quick MCQs

Q1. In superposition, when one independent voltage source is considered, the other independent voltage sources are ___ and dependent sources are ___.

Short-circuited; retained (left as they are).

Q2. A source has Voc = 10 V and Isc = 2 A. Max power to a load?

Rth = 5 Ω; Pmax = 10²/(4×5) = 5 W.

Q3. Delta of three 30 Ω resistors → equivalent star resistor?

10 Ω each.

Q4. Thevenin source Vth = 20 V, Rth = 5 Ω. Max power?

400/20 = 20 W at RL = 5 Ω; efficiency 50 %.

Q5. A network contains only a CCVS and resistors. Vth = ?

0 V (no independent source). Rth is found by a test source and may even be negative.

Q6. Which is true: (a) dependent sources make a network non-linear; (b) power obeys superposition; (c) lossless LC circuit is marginally stable; (d) a diode is bilateral.

(c). Linear dependent sources keep the network linear; power does not obey superposition; a diode is unilateral.

Q7. R(t) = R₀(1 + 0.5 cos ωt) with a v–i relation v = R(t)i. Is it linear? Time-invariant?

Linear: yes. Time-invariant: no (the parameter varies with time).

Q8. Circuit with a port characterised by v = −3i (a negative resistance). Passive or active?

Power absorbed = vi = −3i² < 0 → active.
